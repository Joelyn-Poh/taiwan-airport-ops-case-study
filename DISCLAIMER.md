# Disclaimer

This is an independent educational portfolio project. It is not affiliated with, endorsed by, or based on proprietary data from any ride-hailing platform or travel partner.

All rider, driver, trip, campaign, payment, and marketplace records are synthetic. Public sources are used only to ground the Taiwan travel context. The project deliberately injects data-quality issues so that the SQL cleaning workflow can be demonstrated.

The case represents a fictional ride-hailing platform. All conclusions are hypothetical and must not be interpreted as the operating results of any real company.
